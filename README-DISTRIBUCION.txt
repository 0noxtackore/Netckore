# Netckore Portable Distribution
# Extract and run: Netckore.exe (or double-click Run-Netckore.bat)
# No installation required.
# Created by 0noxtackore

Version: 0.1.0
Platform: Windows 10/11 (x64)
License: MIT / Apache 2.0 / Oracle UPL (same as Fluxckore)

To use:
1. Extract this ZIP to any folder
2. Double-click Netckore.exe (or Run-Netckore.bat)
3. Select categories and click Diagnóstico

Troubleshooting:
- If the window is blank: install Microsoft Edge WebView2 Runtime
- If you see SmartScreen: this executable is unsigned; click More info > Run anyway
- If nothing starts: check netckore-startup.log in %LOCALAPPDATA%\Netckore

For more information: https://github.com/0noxtackore/netckore
